# Contributing to FraudGuard NG

Thank you for your interest in contributing! This project is designed to protect Nigerian financial systems from fraud.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/fraudguard-ng.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Run tests
6. Submit a pull request

## Code Standards

### Go
- Follow [Effective Go](https://go.dev/doc/effective_go)
- Run `go fmt` before committing
- Add tests for new functions

### Python
- Follow PEP 8
- Use type hints
- Run `black` and `isort` before committing

## Security

If you discover a security vulnerability, please email security@fraudguard.ng instead of opening a public issue.
